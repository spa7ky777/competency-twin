# Overfitting in Machine Learning

Overfitting happens when a model learns the training data too closely, including noise, and then performs poorly on new data.

## Signs
- Training accuracy is high, validation accuracy is much lower.
- The model memorizes examples instead of learning general patterns.

## How to reduce overfitting
- Use more training data when possible.
- Apply regularization (L1, L2, dropout).
- Use simpler models or early stopping.
- Use cross-validation to estimate generalization.
