# Classification vs Regression

Supervised learning has two common task types.

## Classification
Predict a discrete label. Examples: spam vs not spam, disease present vs absent.

## Regression
Predict a continuous number. Examples: house price, temperature.

## Evaluation
- Classification: accuracy, precision, recall, F1, ROC-AUC.
- Regression: MAE, MSE, RMSE, R-squared.

Do not use classification accuracy as the only metric on imbalanced data.
