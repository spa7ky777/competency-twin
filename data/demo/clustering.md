# Clustering

Clustering is unsupervised grouping of similar items without using labels.

## Common algorithms
- K-means: partitions points into k clusters using centroids.
- Hierarchical clustering: builds a tree of clusters.
- DBSCAN: finds dense regions and can mark outliers.

## Notes
- Choose k carefully for k-means (elbow method, silhouette score).
- Scale features before distance-based clustering.
